📘 README — Employee Management System
🐍 Python OOP Project | 📂 File: PY 5.py
✨ Project Overview
This Python project demonstrates Object-Oriented Programming (OOP) by creating a Person, Employee, and Manager system. It uses inheritance and method overriding to display details for each type of record.
🎯 Features
⦁	👤 Create a Person with name and age.
⦁	💼 Create an Employee with name, age, employee ID, and salary.
⦁	👨‍💼 Create a Manager with employee information and department.
⦁	📋 Show saved details for Person, Employee, or Manager.
⦁	🚪 Exit the system safely.
🧠 OOP Concepts Used
⦁	🏗️ Classes and Objects
⦁	🧬 Inheritance — Employee inherits from Person, and Manager inherits from Employee.
⦁	🔄 Method Overriding — each class defines its own show_details() method.
⦁	♻️ super() — used to initialize inherited attributes.
▶️ How to Run
1. Open the file PY 5.py in a Python editor such as IDLE, VS Code, or PyCharm.
2. Run the program.
3. Select an option from the menu and enter the requested information.
4. Choose option 5 to exit.
🖥️ Menu Options
Option	Action
1	Create a Person 👤
2	Create an Employee 💼
3	Create a Manager 👨‍💼
4	Show Details 📋
5	Exit 🚪
